# Empty-state illustrations

These application-bundled assets are sourced from the official Vuetify empty-state documentation examples:

- `vuetify-empty-state-connection.svg`: <https://cdn.vuetifyjs.com/docs/images/components/v-empty-state/connection.svg>
- `vuetify-empty-state-teamwork.png`: <https://cdn.vuetifyjs.com/docs/images/components/v-empty-state/teamwork.png>

The connection SVG's solid white canvas was removed locally so the illustration can sit on the application's light or dark surface without a rectangular white background. The illustration itself is otherwise unchanged.
